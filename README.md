# Fuzzy Systems Experiments

A notebook-based project exploring fuzzy logic systems and how fuzzy rules and membership functions can be used for reasoning under uncertainty.

---

## Overview

This project focuses on the fundamentals of **fuzzy systems**, including fuzzy sets, membership functions, and rule-based inference. The notebook demonstrates how fuzzy logic can model imprecise or uncertain relationships that are difficult to capture with traditional crisp logic.

The emphasis is on understanding how fuzzy systems behave and how design choices affect outputs.

---

## What the Project Does

* Defines fuzzy sets and membership functions
* Constructs fuzzy rule bases for inference
* Applies fuzzy reasoning to example inputs
* Visualizes membership functions and system behavior
* Analyzes how changes in rules or parameters affect results

---

## Tools Used

* Python
* Jupyter Notebook
* NumPy
* Matplotlib
* Fuzzy logic concepts and methods
